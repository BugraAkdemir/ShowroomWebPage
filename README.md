# 🛒 Showroom Web Page (PHP Admin Panel)

Bu proje, ürün ve kategori yönetimine sahip, küçük ölçekli işletmelerin vitrin/ürün tanıtımı yapabilmesi için hazırlanmış **hafif bir showroom CMS sistemidir**.  
Tamamen PHP tabanlıdır ve admin panel üzerinden içerik yönetimi yapılabilir.

---

## 🚀 Özellikler

### ⭐ Kullanıcı Tarafı (Frontend)
- Modern ve sade bir showroom arayüzü  
- Ürün detay sayfaları  
- Kategori bazlı ürün listesi  
- Responsive (mobil uyumlu) tasarım  
- Hızlı yükleme için optimize edilmiş görseller  

### 🔐 Admin Panel
- **Kategori ekleme / silme / güncelleme**
- **Ürün ekleme / silme / güncelleme**
- Ürün görselleri yükleme (uploads klasörü)
- Basit ama işlevsel yönetim paneli
- Minimal tasarım + kolay kullanım

### 🧩 Teknik Yapı
- PHP (core)
- MySQL veya dosya tabanlı yapı kullanılabilir
- HTML5 / CSS3 / JS
- FontAwesome ikon desteği
- Upload sistemi (jpg/png destekli)

---

## 📂 Önemli Dosyalar
- `admin/` – Yönetim paneli sayfaları  
- `uploads/` – Ürün görselleri  
- `config.php` – Veritabanı / yapılandırma dosyası  
- `urun.php` – Ürün detay sayfası  
- `tekkurun.php` – Tek ürün görünümü  
- `index.php` – Anasayfa ve vitrin
